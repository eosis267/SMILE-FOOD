# SMILE-FOOD

A modern food delivery and multi-vendor marketplace platform built with React, Vite, Tailwind CSS, and Supabase.

## Features

- **Multi-Role Experience**: Tailored interfaces for Customers, Vendors, Delivery Riders, and Administrators.
- **Customer Portal**: Browse menus, live cart management, secure checkout, and real-time delivery tracking.
- **Vendor Dashboard**: Menu catalogue management, order fulfillment, and earnings tracking.
- **Rider Portal**: Delivery dispatch, navigation tracking, and payout monitoring.
- **Admin & Moderation**: Ledger audits, dispute handling, user role management, and analytics.
- **Supabase Backend**: Real-time database, authentication, row-level security (RLS), and ledger integrity.

## Tech Stack

- **Frontend**: React 19, Vite, React Router 7, Tailwind CSS v4, Lucide Icons, Recharts
- **Backend / Database**: Supabase (PostgreSQL, Auth, RLS policies, Realtime)
- **Tooling**: Oxlint

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm, yarn, or pnpm

### Installation

```bash
git clone https://github.com/eosis267/SMILE-FOOD.git
cd SMILE-FOOD
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```
